INDRA DEO — PERSONAL PORTFOLIO WEBSITE
=======================================

This is a responsive, custom-coded starter portfolio using HTML, CSS, and JavaScript.
Design direction: luxury black, emerald green, modern blue, and subtle technology-inspired details.

FILES
-----
index.html  Main website content
style.css   Layout, responsive styling, colours, typography
script.js   Mobile navigation and automatic footer year

IMPORTANT BEFORE PUBLISHING
---------------------------
1. Open index.html and replace YOUR_EMAIL@example.com with your real public contact email.
2. Replace https://www.linkedin.com/ with your own LinkedIn profile URL.
3. Add your real photograph, exact education, experience, awards, and completed projects.
4. Review every statement and remove anything that does not accurately describe you.
5. Test all links on both a phone and a computer.

PUBLISH FREE WITH NETLIFY (simple option)
-----------------------------------------
1. Extract this ZIP file on your computer.
2. Visit https://app.netlify.com/drop
3. Sign in or create a Netlify account if prompted.
4. Drag the extracted folder (the folder containing index.html) into the upload area.
5. Wait for deployment to finish. Netlify will show a public website address.
6. Open that address on your phone and test it.
7. You can change the generated site name in Netlify's site settings. A custom domain is optional and usually costs extra.

ALTERNATIVE: GITHUB PAGES
-------------------------
Upload the three website files to a GitHub repository, then open repository Settings > Pages and enable deployment from the main branch. See https://pages.github.com/ for current instructions.

NOTES
-----
- This starter site does not include a backend, a working contact form, analytics, or a CMS.
- The contact email link opens the visitor's email app; it is not a form submission system.
- Google Fonts require an internet connection. System fallback fonts are provided.
- Hosting providers may change their interfaces and requirements over time.
